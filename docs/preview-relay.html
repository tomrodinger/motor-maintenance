Relay — six inside-the-box variants

Button behaviour is unchanged from Option 1: invert to accent, icon becomes a check. What differs is the container glow, which now never paints outside the element — each is drawn on an inset layer with the host's own border radius, so nothing can be clipped by a card edge. Click any button. "Fire all" shows what a burst looks like.

R1 and R6 originate at the control you actually pressed; the rest are geometry-only.

My pick: R1.

It keeps the causal link that made Option 1 work — the light comes out of the thing you pressed — but now stays inside the card, so the effect reads as the motor lighting up rather than a ring being sliced off. On a table row it degenerates gracefully into a soft directional bloom because the row is short and wide. R4 is the safest, quietest choice if R1 still feels too active in a burst; it is the only one with no movement at all. R5 is the most "instrument", but it fires the same regardless of which of the four buttons you pressed, which throws away information.
